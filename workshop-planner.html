Tool Operating Clearance Defaults

Minimum clear space (in feet) required around each machine type, measured from its un-rotated footprint — Left/Right run along the tool's infeed/outfeed axis for most feed-through machines, Top/Bottom are side clearance. The zone rotates with the tool if you rotate it on the grid.
