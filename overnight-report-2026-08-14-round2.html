Workshop Planner
✓
Swap Width/Length now actually rotates a custom shop shape
The button only ever resized the rectangular width/length fields — for a custom-drawn shape, the outline's own points are separate fixed coordinates that never moved, so nothing visibly happened. It now rotates every point in the shape 90° to match, verified with both a square shop (50×50, matching what you described) and a rectangular one.
Check: Draw a custom shape, then hit the swap button — the outline itself should turn, not just the number fields.
✓
+ Add Custom Tool and Collapse All swapped positions
+ Add Custom Tool now sits right after the search box; Collapse All moved below the My Custom Tools category.
Check: Top of the left sidebar.
✓
Laguna C-Flux 2 dust collector no longer renders sideways on the ceiling
The code that recognizes "this is a floor-standing collector, not an overhead duct" only matched two specific product names (JET DC-1100VX, Oneida Dust Deputy) — your Laguna wasn't on that list, so it fell into the duct-rendering path instead. Extended the same check (in three places it was duplicated) to also recognize the Laguna. Confirmed in the actual 3D viewer — it now renders upright on the floor.
Check: Place the Laguna C-Flux 2, view in 3D.
✓
New toggle: "Show Cabinets on other layers"
Cabinets always showed as background context on every layer with no way to turn it off. New checkbox in the Layers bar (on by default, matching the old behavior) lets you hide them from Tools/Dust Collection/Lighting/All — the dedicated Cabinets view is unaffected either way. Also applied to the per-layer PDF export, so a printed page matches what the toggle is set to.
Check: Layers bar, next to the Cabinets tab.
✓
Metric now covers the grid ruler and every already-placed item's label
This was the real gap in the earlier metric work: the ruler along the top/left edge always showed raw feet numbers, the Grid Scale dropdown ("1' Boxes") never changed, and — the big one — anything you'd already placed on the board before switching units kept showing its old imperial label, since nothing was refreshing it. All three are fixed: the ruler now steps in clean half-meter increments when metric is on, the Grid Scale options show the cm equivalent, and switching units now re-renders every tool/cabinet/wall-feature label already on the board (including correctly recalculating a wall cabinet's mount height from its real stored value, not just relabeling whatever text was already there).
Check: Place a few things, then flip Imperial/Metric — the ruler, grid-scale dropdown, and every label on the board should all update together.
3D Shop Viewer
✓
Side panels no longer overlap
Add Item was hardcoded to sit at a fixed pixel position, on the assumption the panel above it would never grow past that point. It did — the Move Objects checkbox I added last round made that panel taller. Now measures the real panel height instead of guessing, so this can't silently break again the next time that panel's content changes.
Check: Right side of the 3D viewer — both panels should sit cleanly stacked with a gap between them.
✓
Camera controls tuned for finer movement
Scroll-to-zoom now zooms toward wherever your cursor is pointing instead of always toward the fixed center of the view — this was probably the biggest single contributor to the "hard to move around" feeling. Rotate/pan/zoom speed all nudged down for more control, and there are now sane limits on how far in/out you can zoom so a stray scroll can't fling you out to nothing or into a wall.
Check: Scroll to zoom in on one specific corner of the shop, and try a slow drag to orbit — both should feel noticeably more controlled. Let me know if it's still not right — this one's about feel, so more specific feedback (too fast? too slow? something else entirely?) will get it closer faster than me guessing again.
